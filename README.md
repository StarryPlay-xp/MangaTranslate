# 漫译（MangaTranslate）

自用的 iPhone App：在 App 内置的浏览器里看日漫、韩漫网页，先用 Apple Vision 在手机上找出文字，再交给大模型看图翻译成简体中文，最后把译文贴回原来的位置。大模型服务可以自己配置：默认是 DeepSeek，也能换成其他 OpenAI 兼容或 Anthropic 格式的服务，或者局域网里自己部署的模型。

## 目录结构

- `MangaTranslate.xcodeproj`、`MangaTranslate/`：iOS App
- `Packages/MangaCore/`：App 和验证工具共用的核心逻辑（文字识别、合并文字块、编号图、大模型翻译）
- `Config/Info.plist`：Info.plist 里写不进项目设置的部分（允许用 http:// 访问局域网），编译时自动合并
- `Tools/OCRProbe/`：Mac 上的识别与翻译验证工具，用法见它的 README
- `samples/`：验证用的截图，不提交到仓库

## 在模拟器里运行

1. 用 Xcode 打开 `MangaTranslate.xcodeproj`
2. 窗口顶部选择 `MangaTranslate` 和一台 iPhone 模拟器，按 ⌘R 运行
3. 首页点"内置示例页"。在设置里打开"试运行"，可以不联网先检查识别和贴字效果

## 装到自己的 iPhone（免费 Apple ID）

1. Xcode → Settings → Accounts，添加自己的 Apple ID
2. 在左侧选中项目 → TARGETS 里的 `MangaTranslate` → Signing & Capabilities，Team 选自己的 Personal Team。如果提示 Bundle Identifier 已被占用，改成一个别人不会用的名字
3. 用数据线连接 iPhone，在 Xcode 顶部选择这台 iPhone，按 ⌘R 运行
4. 第一次安装需要在 iPhone 上操作：设置 → 隐私与安全性 → 打开"开发者模式"并重启；然后在 设置 → 通用 → VPN 与设备管理 里信任自己的开发者证书
5. 免费签名 7 天后失效，到时连上 Mac 再运行一次就行，App 里的数据一般不会丢

选好 Team 后，项目文件里会多出一行 `DEVELOPMENT_TEAM`。这是开发者团队编号，不是密钥，提交到仓库没有问题。

## 使用方法

1. 首页右上角进入设置，在"模型服务"里点 DeepSeek 的"编辑"，粘贴 API Key 后点"保存"。Key 只保存在这台设备的钥匙串里。想换别的模型，见下面的"模型服务"
2. 在首页的气泡地址栏里输入漫画网址，打开后在底部"更多"菜单里选好原文语言（日语或韩语）
3. 正常往下看就行：自动翻译默认开启，会翻译屏幕上和下方 1.5 屏以内的漫画图片。往下滑时上下工具栏会自动收起，往上滑就会出现
4. 底部中间的"译"字气泡是自动翻译开关，品红色表示开启；正在翻译时，气泡轮廓上有一圈白色虚线在流动。某张图翻译超过 0.6 秒时，图片右上角会出现一个小小的三个点
5. 点一下译文可以临时看原文，再点一下恢复
6. 顶栏的星标把当前页面加入书架；"更多"菜单里还有"只翻译这一屏"、清除译文、刷新和设置

首页的"继续看"会记住上次看的页面，点开后回到上次看到的位置；书架显示每个书签的页面缩略图。

翻译过的图片会按模型服务分别缓存译文，重看时直接显示，不再调用模型；换了模型会重新翻译，切回原来的模型时直接用缓存。人名等专有名词的译法按网站记住，下一话继续沿用。缓存和术语记忆都可以在设置里清除。

翻译时，漫画图片（带编号框）和识别出的文字会发送到你配置的地址。关掉"把图片发给模型"时只发文字。

## 模型服务

设置里可以保存多个模型服务，点一项就设为当前使用，方便换着用、比较译文。每个服务包括：

- **接口格式**：DeepSeek、Ollama、LM Studio、vLLM 等大多数服务用"OpenAI 兼容"（Chat Completions）；Claude 和兼容 Anthropic 的服务选"Anthropic"（Messages）
- **请求地址**：带不带 `/v1`、结尾有没有斜杠都行，编辑页会显示实际发送的完整地址，例如 `https://api.deepseek.com` → `https://api.deepseek.com/v1/chat/completions`
- **模型名**、**API Key**（可以不填，本地服务一般不需要；每个服务的 Key 分开存在钥匙串里）
- **支持看图**：模型不能看图就关掉，只发识别出的文字
- **JSON 模式**：OpenAI 兼容格式下要求模型只输出 json。有的模型不支持会报错，关掉后 App 也能从普通回复（包括 ```json 代码块）里提取译文
- **最长等待**：本地小模型慢，可以设到 5 或 10 分钟

编辑页的"测试连接"只发一条很短的文字请求，用来确认地址、模型和 Key 能用。

费用：目前只有 DeepSeek 的 `deepseek-flash` 有价格数据，会估算费用；其他服务只显示 token 数。DeepSeek 专用的关闭思考参数也只发给 DeepSeek。

从旧版升级时，原来填的 DeepSeek Key 会自动搬到内置的 DeepSeek 配置里，不用重填。

### 用局域网里自己部署的模型

1. 在电脑上启动模型服务，并允许局域网访问。例如 Ollama 要设置环境变量 `OLLAMA_HOST=0.0.0.0`；LM Studio 要在本地服务器的设置里打开局域网访问
2. 查电脑的局域网 IP（Mac：系统设置 → Wi-Fi → 详细信息），手机和电脑连同一个 Wi-Fi
3. 在 App 里添加"OpenAI 兼容格式"的服务，地址填 `http://电脑IP:端口`（Ollama 默认 11434，LM Studio 1234，vLLM 8000），模型名填服务里的模型名。看不了图的模型记得关掉"支持看图"
4. 第一次连接时系统会询问是否允许漫译访问本地网络，选"允许"。以后可以在 iPhone 设置 → 隐私与安全性 → 本地网络 里修改

App 只允许对局域网地址（私有 IP、`.local`、`localhost`）用 `http://`，其他地址必须用 `https://`。局域网服务一次只翻译一张图，免得小模型排队超时。

## 当前版本的限制

- 自动翻译只处理网页里的普通图片（`<img>`）。漫画画在 canvas 上，或被切块打乱后再拼起来的网站，需要用"只翻译这一屏"
- 只翻译已经加载好的图片；快速滑过去的图不会翻译，滑回来时会补上
- 翻译失败的图不会自动重试；清除译文后重新打开自动翻译即可重试
- 放在内嵌框架里的图片不会被翻译
- 只在模拟服务上验证过 OpenAI 兼容和 Anthropic 两种格式，还没有接真实的本地模型和其他服务商测试
